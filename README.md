# 烬影·墨刃 · Godot 4 原型（方案 A）

3D 风格化动作游戏原型，单人开发可达成的上限：魂味战斗循环 + 架势系统。

## 环境

- **Godot 4.3 或更高**（Forward Plus 渲染器）
- 不依赖任何外部资产，所有模型/材质程序化生成，方便你后续在编辑器里替换为美术资源。

## 运行

1. 打开 Godot 4 → `Import` → 选择本目录的 `project.godot`
2. 按 `F5` 运行主场景 `scenes/main.tscn`
3. 鼠标会被捕获，`ESC` 释放鼠标，`F` 重新捕获

## 操作

| 按键 | 动作 |
|---|---|
| W A S D | 移动 |
| 空格 | 跳跃 |
| J | 轻击（三连） |
| K | 重击 |
| L | 闪避（前 0.22s 无敌） |
| C | 识破（parry 窗口 0.3s） |
| Q | 锁定最近敌人 |

## 已实现的核心战斗逻辑

- **轻击三连**：带连招缓冲（recovery 阶段输入下一击可衔接）
- **重击**：高伤害/架势，长前摇
- **闪避无敌帧**：前 22 帧无敌，消耗体力
- **体力系统**：攻击/闪避消耗，延迟回复
- **架势系统**（敌人）：架势归零 → 崩坏硬直 → 处决伤害×2
- **锁定视角**：Q 键切换最近敌人
- **命中判定**：Area3D hitbox，单次攻击不重复命中

## 下一步（需在编辑器内手工完成）

1. **替换占位模型**：当前角色/武器/敌人都是胶囊+圆柱。把 `player.gd`/`enemy.gd` 里的 `_build_self()` 改成加载你做的 GLB 模型即可。
2. **动画**：当前攻击是 `Tween` 驱动的棍子旋转。接入 `AnimationPlayer` 后把 `_start_attack` 里的 tween 换成 `play("atk_light")`。
3. **场景/关卡**：`main.gd` 的 `_build_world()` 只有一块地板和六根柱子。在编辑器里搭关卡更直观。
4. **音效/特效**：攻击命中时加粒子和音效。
5. **打包**：项目 → 导出 → 选择 Windows / 平台生成安装包。

## 设计说明

- 画质上限：**风格化（非写实）**。受限于单人产能与 Godot 渲染管线，不可能达到虚幻 5 的 AAA 水准，但可以做出《泰坦之魂》《师父》那一类有美术风格的动作游戏。
- 所有战斗数值集中在 `scripts/combat.gd`，方便调参。
